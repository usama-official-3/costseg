# CostSeg SI

Frontend for [costseg.si](https://costseg.si) — cost segregation studies accelerated by Super Intelligence.

## Stack

- Next.js 16 (App Router)
- TypeScript (strict)
- Tailwind CSS v4
- Lucide React, React Hook Form, Zod
